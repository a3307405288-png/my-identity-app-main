# US Identity Generator (美国身份生成器)

A sophisticated mock data generator for developers and testers. This tool creates realistic US identities with visual asset previews and bilingual support.

这是一个专为开发人员和测试人员设计的虚拟数据生成器，可生成逼真的美国身份信息，并提供证件的视觉预览和双语支持。

![Gemini_Generated_Image_688pjc688pjc688p](https://github.com/user-attachments/assets/f2864279-0e1d-481f-a5d5-35b775a9f2d2)

## ✨ Features (功能特性)
 
- 🇺🇸 **Realistic Data**: Generates consistent US identities including Names, SSNs, Phone numbers, Emails, and Addresses.
- 💳 **Visual Assets**: Real-time rendering of responsive ID Cards and Credit Cards with holographic effects.
- 🌐 **Bilingual**: Seamless switching between English and Chinese (Simplified) interfaces.
- 📱 **Responsive Design**: Optimized experience for both desktop and mobile devices.
- 🔒 **Privacy First**: All data is generated locally in your browser using pure algorithms. **No data is stored or transmitted.**
- 📋 **Quick Actions**: One-click copy functionality for all data fields.

## 🛠 Tech Stack (技术栈)

- **Framework**: React 19
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Language**: TypeScript
- **Build Tool**: Parcel / Vite (depending on your setup)

## 🚀 Getting Started (如何运行)

1. **Clone the repository**
   ```bash
   git clone <your-repo-url>
   cd <repo-name>
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm start
   # or if using vite
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```
